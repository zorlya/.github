# zorlya/.github

The organization's public profile and its default community health files.

| File | What it does |
|---|---|
| [`profile/README.md`](profile/README.md) | The text on the [Zorlya organization page](https://github.com/zorlya). `logo.svg` and `logo-dark.svg` next to it are the wordmark for light and dark themes |
| [`SECURITY.md`](SECURITY.md) | The security policy that every repository in the organization without its own file inherits |

Keep the wording plain and specific: no emoji, no exclamation marks, and no counts that the data does not back.
