# Security

To report a security problem in anything Zorlya runs, write to [security@zorlya.com](mailto:security@zorlya.com). Say what you found, where, and the steps to see it. We reply within two working days.

Please do not open a public issue for a security problem, and do not read, change or delete other people's data to prove a point. What we do with resumes and accounts is on [zorlya.com/security](https://zorlya.com/security).

This file is the default for every repository in the organization that has no `SECURITY.md` of its own.
